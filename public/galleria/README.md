# Galleria foto dell'evento

Carica qui le foto della festa: appariranno automaticamente nella sezione
"Galleria fotografica" della home, senza bisogno di modificare il codice.

## Come caricare le foto da GitHub

1. Apri questa cartella (`public/galleria`) su GitHub.
2. Usa "Add file → Upload files" e trascina le foto.
3. Fai il commit direttamente sul branch di lavoro.

## Formati e consigli

- Formati supportati: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Le foto vengono mostrate in ordine alfabetico per nome file: se vuoi un
  ordine preciso, rinominale ad esempio `01-hero.jpg`, `02-laboratori.jpg`, ecc.
- Esporta le foto già ridimensionate (max ~2000px sul lato lungo) e
  compresse, per non appesantire il caricamento del sito.
- Evita nomi file con spazi o accenti se possibile (es. `piazza-bartolo.jpg`
  invece di `piazza bartolo è.jpg`).

Questo file (`README.md`) non è una foto e viene ignorato dalla galleria.
